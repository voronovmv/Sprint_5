# Sprint 5 - UI автотесты для Stellar Burgers

Проект содержит автотесты на Selenium и Pytest для проверки сервиса Stellar Burgers.

Проверяется:
- Регистрация
- Вход различными способами
- Переход в личный кабинет
- Переход в конструктор
- Выход из аккаунта
- Работа вкладок конструктора

Запуск тестов:

pytest -v
